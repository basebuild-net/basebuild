Basebuild
=========

A desktop control plane for AI coding agents.

---

The problem
-----------

OhMyPi (OMP) is one of the most capable coding agents available today — it
routes across every major model, runs skills, manages sessions, and ships a
rich terminal UI. But it lives in a terminal. That means:

  - Juggling multiple sessions is an exercise in tmux tabs and lost context.
  - Turning a big goal into scoped work means prompting, guessing, and
    copy-pasting tasks into a tracker.
  - Keeping track of what the agent should do next is a scroll-back game.

The terminal is a great surface for an agent. It is a poor surface for
managing one.


The idea
--------

Basebuild is a cross-platform desktop application (Windows, macOS, Linux)
that wraps OMP and turns it into a visual, end-to-end workflow.

It is not a new agent. It is a control plane for the agent you already have.
Basebuild gives the agent a persistent project context, a plan pipeline, and
one-click ways to send work to the agent.

The core workspace is three columns:

  - Projects on the left — sessions, files, and recent work.
  - Workspace in the center — terminal and source control.
  - Plans on the right — the single most important surface.

Plans are the primary unit of work. A plan has a stable reference id, a title,
a description, a priority, and a status that flows through
`draft → openspec → waiting → in_progress → finished`. Plans can be created
manually, enhanced by AI, or generated from a project goal.


The workflow
------------

  1. Set a goal.
     Tell Basebuild what you want the project to become. This can be a one-line
     final result or a loose brainstorm.

  2. Generate plans.
     Click "Generate Plans". Basebuild uses a skill-backed prompt with your goal
     and the real project context to return a prioritized list of MVP plans.
     Pick the ones you want and approve them into the draft lane.

  3. Suggest more.
     Click "Suggest More Plans" to send the existing plans and goal back to the
     model. It returns additional plans scoped to what is still missing.

  4. Create and enhance.
     Quickly add a task yourself, then click "AI Enhance" to have the model
     rewrite it with clearer scope, tags, and priority.

  5. Focus and run.
     Move a plan into focus. Basebuild shows the plan context and lets you copy
     its reference id or open it directly in a terminal or OMP session. The
     agent gets the exact plan context and starts working.

  6. Finish and archive.
     When a plan is done, mark it finished. It slides into a collapsed finished
     pile, keeping the workspace clean.

Throughout, raw terminal panes and source control stay in the center so you
can always fall back to real tools.


Why it works
------------

Basebuild is possible because OMP already speaks a host protocol. The app
launches OMP over stdio and becomes its host, reading events and sending
prompts. Plans get a stable reference id that can be injected into any
terminal or OMP session, so the agent always knows which piece of work it is
on. The plan panel is local-first: plans live in SQLite, generation is driven
by editable skills, and nothing requires a cloud backend.


Distribution
------------

Tauri v2 (Rust core + native webview), packaged for Windows, macOS, and
Linux in ~10MB binaries. A Cloudflare Worker serves update manifests and
release notes; binaries live on Cloudflare R2 or GitHub Releases. The app
checks for updates on startup and self-updates in the background.


In one line
-----------

Basebuild is the desktop app that turns OMP from a terminal tool into a
managed, visual, idea-to-execution workflow — with plans, not prompts, as the
primary interface.
